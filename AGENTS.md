# Working on the toolkit

Read README.md, docs/api.md and docs/review.md before making changes.
Run `npm run check` for source or example changes. Keep the library free of I/O
and third-party runtime dependencies unless explicitly requested otherwise.

This repository is private for review; public visibility, an open-source license
and npm publication require the owner's explicit instruction. Use synthetic data
only. Do not copy SDKs, recordings, reports, media, credentials or private source
project documents into this repository.

The extraction manifest hashes the initial source copies. If behavior changes,
document the divergence and add a regression test; preserve the initial provenance.
Keep thresholds and game outputs described as experimental engineering choices.
