# Case study graphics

Selected graphics from [Peter Corbett’s Mind Field case study](https://corbett.vc/mindfield/),
added at the project owner’s request on November 27, 2026. Files are unchanged
copies of the site assets; exact source URLs and SHA-256 hashes are in
[sources.json](sources.json).

| File | Description |
| --- | --- |
| [temple-gate.webp](temple-gate.webp) | Temple gate artwork used at the top of the case study. |
| [maze-poster.jpg](maze-poster.jpg) | Maze video poster, visibly labeled synthetic rehearsal. |
| [wall-poster.jpg](wall-poster.jpg) | Silent-practice wall video poster, visibly labeled synthetic rehearsal. |

These illustrate the original experience; the toolkit does not include the full
application or its presentation renderer. They are not participant recordings or
validation evidence. No additional reuse license is granted by including them;
this repository remains private for review with licensing undecided.

## Training screenshots

The owner also requested the `/training` screenshots in [training/](training/).
These were captured from the real interface using isolated synthetic fixtures,
not downloaded from the case study. See the [annotated walkthrough](../training-walkthrough.md)
and [capture manifest](training/manifest.json) for method, source revision,
dimensions and checksums. No participants or saved sessions were used.
